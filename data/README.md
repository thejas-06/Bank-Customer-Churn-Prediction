# 📂 Data Layer & Schema Documentation

This directory contains the raw and preprocessed datasets for the Bank Customer Churn Prediction system.

---

## 📑 File Inventory

| File Name | Records | Columns | Description |
|---|---|---|---|
| **`Churn_Modelling.csv`** | 10,000 | 14 | Raw retail banking customer dataset containing demographics, account details, and historical attrition labels. |
| **`churn_cleaned.csv`** | 10,000 | 13 | Preprocessed, index-aligned feature matrix generated by `02_Feature_Engineering_and_Preprocessing.ipynb` and used for offline model experimentation. |

---

## 📊 Raw Data Dictionary (`Churn_Modelling.csv`)

| Column Name | Data Type | Constraint / Range | Description |
|---|---|---|---|
| **`RowNumber`** | Integer | 1 – 10,000 | Row index identifier (dropped during preprocessing). |
| **`CustomerId`** | Integer | Unique 8-digit ID | Unique customer account number (dropped during preprocessing). |
| **`Surname`** | String | Text | Customer family name (dropped during preprocessing). |
| **`CreditScore`** | Integer | 350 – 850 | Customer credit rating score. |
| **`Geography`** | String | `France`, `Germany`, `Spain` | Primary country where the customer account is registered. |
| **`Gender`** | String | `Female`, `Male` | Customer biological gender. |
| **`Age`** | Integer | 18 – 92 | Customer age in years. |
| **`Tenure`** | Integer | 0 – 10 | Number of years the customer has maintained an account with the bank. |
| **`Balance`** | Float | $0.00 – $250,898.09 | Current liquid deposit balance held in the bank. |
| **`NumOfProducts`** | Integer | 1 – 4 | Number of distinct bank financial products subscribed to (e.g., savings, loan, credit). |
| **`HasCrCard`** | Integer | `0` (No), `1` (Yes) | Binary flag indicating whether the customer owns a bank-issued credit card. |
| **`IsActiveMember`**| Integer | `0` (No), `1` (Yes) | Binary flag indicating whether the customer actively transacts. |
| **`EstimatedSalary`**| Float | $11.58 – $199,992.48 | Estimated annual salary/earnings of the customer. |
| **`Exited`** | Integer | `0` (Retained), `1` (Churned) | **Target Variable**: Indicates whether the customer closed their account. |

## 🎯 Target Distribution & Class Imbalance

```
Class 0 (Retained):  7,963 customers (79.6%)
Class 1 (Churned) :  2,037 customers (20.4%)
Imbalance Ratio   :  ~3.91 to 1
```

* **Modeling Impact**: A baseline model predicting all zeros achieves 79.6% accuracy but identifies 0% of churners. The training pipeline uses cost-sensitive learning (`scale_pos_weight = 3.91`) and threshold calibration (`0.655`) to handle this distribution without distorting real-world probabilities.

## ⚙️ Transformations from Raw to Cleaned (`churn_cleaned.csv`)

During the feature engineering phase, the dataset undergoes the following transformations:

1. **Identifier Pruning**: `RowNumber`, `CustomerId`, and `Surname` are removed (zero generalizable predictive signal).
2. **Feature Engineering**:
   - `ZeroBalance = (Balance == 0).astype(int)`
   - `ProductActivity = NumOfProducts * IsActiveMember`
   - `BalanceSalaryRatio = (Balance / (EstimatedSalary + 1)).clip(upper=35.4762)`
   - `TenureAgeRatio = (Tenure + 0.5) / Age`
3. **Categorical Encoding**:
   - `Gender_Encoded`: Binary mapping (Female = `0`, Male = `1`).
   - `Geography`: One-Hot Encoded with France as dropped base category $\rightarrow$ `Geography_Germany`, `Geography_Spain`.
4. **Statistical Pruning (Point-Biserial $p > 0.05$)**:
   - `HasCrCard` ($p=0.4754$), `Tenure` ($p=0.1615$), and `EstimatedSalary` ($p=0.2264$) are removed due to statistical insignificance.
